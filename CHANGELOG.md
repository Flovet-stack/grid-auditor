# grid-auditor

## 0.1.0

First preview release.

- Expected Figma layout grids (columns, rows, square grids; stretch, min, center and max alignment) with editable breakpoints.
- Control panel (Ctrl/Cmd+Shift+G) with the Layout guide list, saved edits and Copy config.
- Rendered grid: the page's grid, flex and block containers as a tree, with tracks, gaps, padding and gap audit.
- Inspector (Shift+M): hover to draw the element under the pointer.
- Compare: expected vs rendered column edges, with signed deviation labels.

Not included yet: rulers, guides, the toolbar, and React, Svelte and Vue entries.
